Project Description

StudentHub Portal is a simple student-oriented web portal designed to provide important college and academic information in one place.

The portal allows students to access pages such as Home, Login, Registration, Dashboard, Profile, Events, FAQ, Feedback, Contact, and About Us. The Dashboard also provides access to the Time Table and Events sections.

The current project is developed mainly using HTML and CSS, with JavaScript used where required for basic client-side functionality.

Objectives

Create a simple and user-friendly student portal.

Provide easy navigation between different pages.

Allow students to access important college information.

Provide sections for events, timetable, notices, feedback, FAQ, and contact information.

Maintain an organized project structure.

Prepare the project for future development and backend integration.

Main Features

1. Home Page

The Home page introduces the StudentHub Portal and provides navigation to the main sections. It includes portal features, latest news, and reasons to use StudentHub.

2. Login

The Login page provides fields for Email/Username and Password. Basic HTML validation is used, and JavaScript stores the entered values in browser local storage before navigating to the login details page.

3. Registration

The Registration page is intended for creating a new student account.

4. Dashboard

The Dashboard provides links to:

Time Table

Events

It also contains:

Latest Notices

Quick Information

5. Profile

The Profile page is intended to display student personal information.

6. Timetable

The Timetable page is intended to display the student's weekly class schedule.

7. Events

The Events page displays upcoming college events with their date and venue. It also provides participation instructions.

8. FAQ

The FAQ page provides answers to common questions related to registration, login, profile updates, events, and contacting the college.

9. Feedback

The Feedback page contains a form with:

The form also contains Submit and Reset buttons.

Design

The project uses a common StudentHub header, navigation bar, content sections, and footer. The pages use a simple academic portal layout with centered content boxes, tables, forms, and navigation links.

The uploaded pages use style.css as the common external stylesheet and also contain page-specific CSS where required.

Dashboard Details

The Dashboard contains two main feature boxes:

Time Table – opens the timetable page.

Events – opens the events page.

It also displays latest notices and quick information.

Events

The Events page currently contains examples such as:

Technical Fest

Sports Week

Coding Competition

Seminar on AI

Cultural Program

Each event contains a date and venue.

FAQ

The FAQ section includes questions about:

Student registration

Feedback Form

The feedback form collects student information and feedback. The rating options are:

Good

Contact Information

The Contact page contains the college address, contact number, and StudentHub email information used in the project.
